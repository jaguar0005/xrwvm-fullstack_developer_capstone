# Full Stack Cloud Developer Capstone Project - Dealership Application

## Project Overview
This repository contains the completed Capstone Project for the IBM Full Stack Software Developer Professional Certificate. In this project, a full-stack responsive web application was designed, developed, and deployed for Cars Dealership, a national car retailer in the United States.

## Architecture & Microservices
- **Frontend:** React.js, HTML5, CSS3, Bootstrap
- **Backend:** Python, Django, REST APIs
- **Database & Microservices:** Node.js, Express, MongoDB (Dealerships and Reviews)
- **Sentiment Analysis:** Python, Flask, NLTK
- **DevOps & Deployment:** Docker, Kubernetes, IBM Cloud Code Engine, GitHub Actions (CI/CD)

## Features
- User Authentication (Login, Logout, Sign-up/Registration)
- Dealerships directory filtered by US states
- View dealer reviews with sentiment analysis (Positive, Neutral, Negative)
- Submit customer reviews with car make, model, and purchase details
- Django Admin interface for managing Car Makes and Car Models
