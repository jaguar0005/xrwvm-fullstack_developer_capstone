## Description
This repository contains the completed fullstack_developer_capstone project for the Full-Stack Development Capstone course. The application is a national car retailer web application for dealership branches, inventory, and customer reviews built with Django, React, Node.js, Express, MongoDB, and sentiment analysis microservices.
